# DK Easy Renamer v0.2.0

Windows 10/11에서 파일·폴더 이름을 일괄 변경하는 **무료·오픈소스** 프로그램의 첫 공개 버전입니다.

## 주요 기능

- 파일과 폴더를 목록에 추가해 일괄 이름 변경
- 자연 이름순·날짜·크기 정렬과 직접 순서 조정
- 순번 변경, 찾기/바꾸기 등 규칙 조합 및 미리보기
- 변경 전 충돌 확인과 같은 실행 중 실행 취소(Undo)
- 파일·폴더별 **클래식 탐색기 우클릭 메뉴** (선택 설치, 앱 내 적용·해제 가능)
- Windows 11에서는 파일 우클릭 → **추가 옵션 표시 → DK Easy Renamer**
- 인증서 설치·관리자 권한·계정·네트워크 연결 없이 일반 이름 변경 사용 가능

## 설치

**`DK-Easy-Renamer-0.2.0-x64-RELEASE.exe`**를 다운로드한 뒤 설치합니다. 우클릭 메뉴를 쓰려면 설치 중 **'클래식 탐색기 우클릭 메뉴 등록'**을 선택하세요.

**필수:** Windows 10/11, 64비트(x64). .NET 10 실행 환경은 설치 파일에 포함되어 있습니다.

## 보안 및 배포 안내

이 설치본은 **코드 서명되지 않은 무료 배포 버전**입니다. Windows가 알 수 없는 게시자 경고 또는 SmartScreen 경고를 표시할 수 있습니다. 공식 GitHub 저장소에서 내려받았는지 확인하고, 함께 게시된 `SHA256SUMS.txt`와 SHA-256이 일치하는지 확인하세요. **인증서 수동 등록은 필요하지 않습니다.**

Windows 11 새 우클릭의 첫 화면에는 등록되지 않으며, **추가 옵션 표시**에서만 사용할 수 있습니다. Microsoft Defender Smart App Control 등 시스템 보안 정책에 의해 실행이 차단될 수도 있습니다.

앱 안에서 공개 릴리스 확인 기능을 사용할 수 있지만, **서명 없는 설치본을 자동 다운로드/실행하는 기능은 사용하지 않습니다.** 버전 업데이트는 공식 Release에서 설치 파일을 다시 내려받아 진행하세요.

개발용 자체 서명 MSIX를 이용했던 사용자는 새 클래식 배포본 설치 시 기존 확장 등록이 안전하게 제거되어야 합니다. 소유권 충돌 또는 제거 오류가 발생하면 이전 설치본의 메뉴 등록을 먼저 해제하세요. **테스트 인증서를 자동 삭제하거나 추가 신뢰하지 않습니다.**
